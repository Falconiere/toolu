# Semantic judgments

Read the installed `jev` skill once when a task involves semantic decisions;
follow its evidence, question, reuse and uncertainty contract. Load only the
relevant example from its problem-solving reference.

Useful task-specific questions include search relevance and answer existence,
claim/source support, debugging hypothesis fit, or review finding triage.
Gather evidence before asking. Reassess when evidence or requirements change.
If the service is unavailable, state that once and continue with explicit
evidence-based reasoning; never invent a result.

Exact verification and authorization stay with the agent and tools.
