# Dashboard status capture

`status.json` contains unmodified responses from two running in-process epic engines: a local registered epic and a reachable peer. The capture uses real HTTP routes, graph files, a worker report, and `ledger.json`, a copy of a real branch plan ledger (its `evidence_tail` cleared) that the capture places in a temporary worktree. It is produced by `dashboard_status_capture_comes_from_running_engines` with `TOOLU_CAPTURE_DASHBOARD=1 cargo test -p toolu-epic-orchestrator dashboard_status_capture`. The temporary peer port and sampled times are capture facts; tests do not assume they remain reachable. The local engine has a status token, so `screen` is an authorized worker screen read (herdr is `off` in tests), `screen_locked` a read without the token (`401`), and `screen_disabled` the peer's reply with no token configured (`403`). `issue` and `peer_issue` are the worker documents the drawer reads.
