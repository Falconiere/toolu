## Deviations

- The user disabled GitHub Actions workflows for this delivery. PR #693 was opened before implementation finished. Local gate and review replace unavailable CI; the user authorized this worker to squash-merge after local clearance, overriding the original epic worker brief's engine-merge handoff.
- The isolated live probe started real Claude Code and Codex agents with Herdr, then mapped them into a paused temporary engine. A native `toolu epic launch` of fake issues would prompt agents to work outside the screen test. The real blocked-host trust dialog was not reproduced; the endpoint's blocked response and attach command are covered by the listener/socket test.
- The first isolated Linux run exposed a pre-existing status-cache test assertion after its two-second TTL; the assertion now checks refresh cleanup before a later `read()` may schedule another refresh.
- The shared Cargo target reused an `xtask` binary compiled in the temporary snapshot clone, whose default repository root is embedded at compile time. Explicit `--root .` makes s4 check this worktree; verify its checked out HEAD before delivery.
- The user changed the final gate to native `cargo xtask gate` because other epics keep taking the shared Colima VM. Run s4 through the ledger's managed-job lease, build the checkout `toolu` binary, then set a task-owned `TMPDIR` and `TOOLU_RESOURCE_HOME` in the leased check so the lease itself still uses the shared resource home. This worktree's `target/debug` comes first on `PATH` so launcher fixtures use the checkout binary. The explicit root guards against a reused `xtask` binary.
- The first native attempt put `TMPDIR` under this Git worktree's ignored `target/`; three real CLI tests failed, including the token URL test whose engine never wrote `http.json` within ten seconds. `git -C "$TMPDIR" rev-parse --show-toplevel` resolved to this worktree. A second attempt under `$HOME/.cache` passed Git's repository probe but failed the engine binding test because this host has `$HOME/.git`; the engine walks ancestor `.git` markers. A `/var/tmp` attempt passed the binding test but failed a docs-review path assertion: macOS canonicalizes `/var/tmp` to `/private/var/tmp`, while that fixture compares paths lexically. Use the canonical `/private/var/tmp` spelling, with no `.git` ancestor, for the task-owned temp directory.
